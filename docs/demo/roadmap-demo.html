Demo 说明

  • 从 Jira 拉取（调整位置）：Quarter 勾选 + 导入从顶部移到 Backlog 标题旁「↻ 拉取」。浮层里是 Quarter、团队 JQL（可直接跳到编辑）和拉取按钮；结果落在 Backlog，入口就在 Backlog。有勾选但未拉取的 quarter 时按钮亮橙点；没有可拉取的内容时按钮显示「已是最新」
  • Quarter 过滤（新）：过滤行最左「QUARTER」，按 Jira「Target Delivery Quarter」筛选，与 Milestone 为 AND。快速候选只平铺当前与下一个 Quarter，一次点击生效（选中的其他 Quarter 会临时出现在快速区）；▾ 浮层列出 Jira 字段选项全部候选（读取失败时回落为当前 Quarter 前 2 后 1，浮层底部可模拟）。筛选后：结束日（已排期 = bar 结束 / 未排期 = Target End）超出所属 Quarter 的条目，Backlog 卡片标「超出 Q · +Nd」、分组头计数；甘特画 Quarter 底色与截止线，超出部分斜纹 + 末端「超出 Nd」
  • Milestone 过滤（新）：顶部过滤行（原 QUARTERS 行）「MILESTONE」多选，数据来自 Jira Custom Labels（customfield_33875 → LBL-288 AIR 2.0 Milestones）。一个过滤同时作用于 Backlog 与甘特：Backlog 只列匹配条目；甘特中未匹配行可淡化 / 隐藏，选中的 milestone 画紫色旗标线，晚于 milestone 的条目在 bar 末端标出天数。日期解析自 LBL description 首行「Milestone: 11/30/26」，识别不到时展示原描述
  • Jira 查询 / 创建（直连 API 与 Agent 执行器双路径）/ AI 缩写 / 协作同步均为模拟
  • 需要 Jira 权限的操作要装 Personal AI 扩展：锁定按钮点击弹出安装引导；拖动排期 / 改 Owner 会先保存在 Roadmap，并出现一行「没有同步到 Jira」+「安装插件开启同步」。打开页拉取在未安装时保持静默（顶栏 扩展未安装 / 已安装 可切换）前往安装 ↗
  • 创建 Jira 双路径：Prompt 留空＝按下方字段直连 Jira API（串行）；填写＝按 Epic 最多 2 路并行交给所选 Agent 执行器（每路只含该组 draft；部分成功也会回写已有 key）。此时下方字段占位变「自动」，已填的值作为约束带给 Agent；执行器无配置时展示引导入口。fixVersion：按各任务 Target End 在发布时间表上的落点列匹配（半开区间，压在分割竖线上属于下一列——和 hover「可赶 Sprint」不是同一口径）。同一列直接填入共享字段；跨列时共享字段留空，交给 Agent 按行 `suggestedFixVersion` 判断，列表内仍逐行显示绿色 chip；输入固定值可覆盖全部。Jira 尚无此版本时留空 fixVersion 继续创建（行上显示 warning），不会因此拒绝整行。失败行展示完整原因，可改字段后点重试，已成功的 ticket 不会再创建
  • Assignee 映射：弹窗内新增 Assignee 行 —— 任务 Owner 优先，没写 Owner 的任务回落到创建人；在「配置映射…」里为系统人员/创建者补全 Firstname Lastname（两个词以上的名字自动推断）。输入实名时可从已有两词人名下拉建议中选择，选中后合并两人（Owner / 创建者 / 成员收成实名，短名保留为映射别名）。直连 API 时转成 firstname.lastname 填 assignee（未映射的留空并橙色提示）；Agent 模式把字段约束 + 人员名单一并写入 Prompt，可点「查看将发送的完整 Prompt」预览。配置后全站（选人列表 / 人员视图 / 提示 / 协作日志）都展示映射后的实名
  • 时间轴缩放：触控板双指捏合或 ⌘+滚轮在甘特任意位置缩放，光标下的日期钉住不动；在顶部时间标尺上双指上下滑动同样缩放（横向滑动仍是平移）；双击标尺复位 100%，已是 100% 再双击 = 整条时间轴收进视口。缩放时右上角短暂显示当前比例与视野跨度
  • Bar 可拖动 / 左右把手伸缩 / 上下换行，按天吸附
  • 单击 bar 展开/收起；草稿双击改任务名 + 描述（创建 Jira 使用）；已创建的双击改备注名（✦ AI 缩写）；备注名换行展示、bar 自动增高；hover 显示原 ticket 名
  • 草稿描述（可选）：快速添加时 Enter 仍是只填标题秒建；点输入框右侧 ≡ 描述（或 Shift+Enter）展开描述框，新建条目弹窗同样有描述字段。有描述的任务 hover 提示最后的灰色小字改为展示描述（无描述仍显示操作提示）。描述会并入 Agent Prompt 由 AI 综合生成最终 description（不必与输入逐字一致）；直连 API 则原文写入
  • 悬浮：bar 左侧 ＋ 添加任务，右侧 ◆＋ 添加阶段节点 / 外部依赖，右上角 × 退回 Backlog（草稿为删除）
  • 阶段节点（Design/Stage/Production/自定义）以菱形标记显示在 bar 下方的标记轨上，按日期定位、可超出 bar 范围；标记可左右拖动改期（按天吸附，拖到边缘自动滚动），单击则打开编辑器改日期 / 改名 / 删除
  • 外部依赖：ETA 与期望分开。ETA = 对方承诺（实心点）：绑定 ticket 时添加即自动读取 Target End 并把节点放在 ETA 上；ticket 没填 Target End 或没有 ticket 时手动填写。期望 = 我们需要的日期（虚线环）。拖动 = 改期望（从 ETA 点上拖会拉出期望环，ETA 不动；拖回 ±1 天内吸附合一），单击 = 设置 / 刷新 ETA。期望早于 ETA 时两点之间画红线并标 +Nd；同一任务多个依赖时 hover 任一节点高亮成对节点。打开页只镜像 Jira status / Target End，不自动改 ETA，有变化时显示琥珀色「Jira 有变更」
  • 在甘特中定位 ⌖：依赖视图里点主任务名或组头 ⌖ → 跳到任务视图高亮该主任务；依赖行 hover「⌖ 甘特」→ 高亮这条依赖的 ETA / 期望节点；人员视图 hover 任务条右端 ⌖ → 展开主任务并高亮该子任务。独立导航，不写顶部搜索 / 不改 Milestone 与依赖筛选；目标被当前过滤隐藏时只临时显示那一行。工具栏出现「← 返回依赖视图 / 人员视图」，回去时恢复滚动位置并闪烁来源行；Esc / × / 手动切视图即结束定位
  • 依赖视图（工具栏「任务 / 人员 / 依赖」）：只列出带依赖的任务，按风险排序；每行完整展示 ETA ● / 期望 ◌ / 晚 Nd 红色带 / 余量点线 / Ticket Target Start→End 斜纹条 / Jira 新日期琥珀箭头。可过滤「晚于期望 / 缺 ETA / Jira 有变更」，行内一键刷新 ETA、催一下（附期望日）、接受 ETA；拖动节点或 ← → 键改期望，改后 toast 可撤销。甘特依赖浮层底部「在依赖视图中查看」可直接定位
  • Backlog 搜索：按标题 / Key / 备注名 / 类型 / Quarter 过滤，多个关键词空格分隔需全部命中；Esc 清空
  • 新建条目：弹窗含 手动创建 与 使用 AI 批量创建。AI 路径默认先预览，勾选「直接创建 Draft」才一次写入；不创建 Jira；无扩展也能用。创建 Jira 仍走原弹窗。要用自己的 Agent 生成 Draft 有两条路：Codex Plugin 导入 https://github.com/ee01/Personal-AI（Path roadmap-service，Branch develop）后装 roadmap-planning；或把 GitHub/线上 Skill 交给 Agent，远程 MCP 默认 http://roadmap.xmnup.com/mcp。
  • 任务可选 Owner：标题里输入 @ 触发建议（可手输自定义），或点输入框左侧头像；直接 Enter 则跳过。Owner 数据来自团队成员表，新名字自动加入；双击任务条可改 Owner。选人浮层搜索框置顶、打开即聚焦，列表限高可滚动，↑↓ + Enter 快速选择，下方空间不足时自动向上翻转
  • 新增任务默认从今天开始、两周长；草稿任务条不再叠创建者名，hover 时在条外浮出灰色「xxx created」
  • 打开 Jira：主/子任务条 hover 左上角出现 ↗ 圆钮，点击新开对应 issue；⌘/Ctrl+单击任务条等效（草稿无 issue 不显示）
  • 人员视图：按人查看任务（近 2 周 / 全部），可添加成员、双击改名、移除空闲成员。任务条左侧色条 + 前缀 chip 标识所属主任务（备注名优先，条太窄只留色条），工具栏「主任务」图例是纯静态色板对照，不联动高亮
  • 聚焦当前任务（人员视图）：单击任务条标记该成员「正在做」（唯一的高亮态：亮色描边 + ✓），可继续单击多选；点到另一个成员的任务会对那个人重新开始多选；已完成（Jira Closed/Resolved，见下条）的任务不参与选中。除了选中的任务，其余全部压暗（未选中的顺延候选 / 放不下最小人天的 stuck / 已完成 / 远任务，压暗程度一致）——顺延预告靠角标（→下周一 / →缩短 / ✕）单独传达。选中后成员名下出现操作点：「其余延至下周 →」把 TA 其余开始日在下周一之前、尚未结束、未完成的任务统一延至下周一开始。长度优先保持；空间不够时按 Jira Original Estimate（空则 3 人天）缩小。若下周一到 Epic Target End 连最小人天都摆不下，弹出确认框：延长 Epic 结束日到 mm-dd，或取消顺延。已开始未做完的同样延后；hover 按钮预览能放下的落点影子。延后非草稿任务自动回写 Jira Target Start/End；延完再按一次不会继续往后推（幂等）。Esc 或点空白处退出聚焦
  • 已完成任务的配色（人员视图 / 甘特）：主任务（Epic）和子任务镜像的 Jira 状态为 Closed / Resolved / Done 时，用独立的浅绿配色 + ✓ 前缀展示，与「过去/当前/未来」的时间配色区分开——镜像状态可能滞后于本地排期日期，一条日期上看是「未来」的任务也可能其实已经关闭。已完成子任务不计入「待延至下周」的候选统计，也不能被标记「正在做」。Demo 里上季度遗留 Epic「Legacy webhook migration…」预置为 Closed
  • 人员视图时间窗平移：近 2 周模式下触控板双指左右滑动整窗平移（窗口长度 14 天不变），或点两端「◂ 更早 / 更晚 ▸」角标平移两周；平移后表头出现「回到今天」，点「近 2 周」按钮同样回到今天。配合聚焦功能：成员先领取了很后面的任务时，滑到时间后方把它标记「正在做」，再一键把眼前的任务延至下周
  • 人员视图任务条标题贴边：任务开始时间被裁到可视范围左侧外（比如已经进行了很久的长任务）时，「主任务前缀 + 标题」这一组会贴在可视范围最左侧显示，不用滚很久才能看到是哪条任务；贴到任务条自己的结束位置后就不再继续贴，交给省略号收尾（保留标题开头，不会露出反直觉的标题尾巴）。不论是双指滑动过程中还是滑完之后都会跟着实时贴边
  • 创建 Jira 后草稿名保留为备注名：回传 jira key 时自动把原草稿标题存为备注名，甘特上展示的名字不因创建（或 Agent 规范化 summary、后续 Jira 刷新）而改变，hover 才看正式 summary。编辑备注名时清空后回车 = 恢复展示原 ticket 名
  • 清理过期：过期 Epic 回退 Backlog（保留子任务记录，重拖回任务视图可还原），过期子任务从任务视图清理
  • 拖入排期：带 Target 日期的卡片按 Target start/end 落位，其余按松手位置 + 预估
  • 拖动 / 伸缩非草稿主/子任务后自动回写 Jira：新的起止日期同步到该 issue 的 Target Start/End（需装扩展；连续拖动只同步最后一次），成功后有轻提示。未装扩展时排期仍保存在 Roadmap，底部出现一行安装提示，不再假装后台同步成功。双击更换非草稿子任务的 Owner 同样回写 assignee（需已映射 Jira 实名，且仅装扩展的浏览器回写）；备注名（缩写）只是本地显示，从不回写
  • 打开页面自动刷新 Jira（仅装扩展）：打开 Roadmap 时静默拉取非草稿主任务 / 子任务的 summary / description / Target 日期 / assignee / status，以及依赖 ticket 的 status / Target End。主任务 Target 变化会挪 bar；Closed/Resolved/Done 的主任务条改浅绿 + ✓。依赖 ETA 不会被自动改写。映射后是同一人的 Owner 不动。Demo 里把顶栏「扩展未安装」切到「已安装」即可触发，被刷新的条目会闪一圈蓝光（仅演示用）
  • 导入 Task（创建 Jira 左侧浅蓝按钮）：拉取甘特上各主任务名下的 Jira Task，按 Key 去重、已存在的不重复导入。日期兜底：Task 未填 Target Start/End 时与主任务同起止；只填其一时按两周落位，且不超出主任务范围
  • 顶栏 JQL 右侧 ✎ 可编辑团队 JQL（下次导入生效）
  • 发布时间表标尺：✎ 弹窗内可为团队配置 Google Sheet 发布时间表（Release / Phase / Date 三列，悬停「查看示例」看格式）。填完地址自动读取，下方「标尺阶段」列出表中出现的阶段：勾选 = 在标尺上展示，🏁 = 作为 release 结束分割节点（有 FF 默认 FF，结束节点必定展示；列区间为半开 [上一班同阶段, 本班同阶段)）。未读取就直接保存也可以，保存时兜底读取并按默认（FF 结束分界 + 全部展示）。配置后表头换成双轴：Sprint 行为主轴（release 名替代月份、按结束分割节点切段、当前 Sprint 高亮橙色），月份降为细行副轴（quarter 标签移除）；正文竖线换成 Sprint 结束分界实线 + 阶段虚线；Pro 刻度直接标注日期；拖动任务时提示可赶的最近 Sprint。Nova Brandy 已预配置（演示只展示 FF / Stage / Pro 三个阶段），RCV Mobile 未配置可体验完整引导流程；清除配置即恢复月份标尺
  • Release 过滤：弹窗内可过滤小版本 —— 预设「仅大版本（尾号 0）」一键保留 26.3.320 这类、过滤 26.3.325 这类；「自定义」用通配符（*0, RIO * 逗号分隔任一匹配即保留），/…/ 包裹按正则。任何档位下方都实时预览保留 / 过滤名单（被滤的划线展示）；规则非法或把 release 全滤掉时自动兜底为不过滤。被滤掉的 release 不参与 Sprint 分段、刻度与可赶 Sprint 提示。Brandy 预设「仅大版本」，可在弹窗切回「全部」对比
  • 标尺临时切换：配置了发布时间表后，工具栏出现 Sprint / 月份 小开关，可随时切回月份刻度对日期（切换态为浅蓝提示）。只影响自己的当前视图，不改团队配置、不同步给他人、刷新即恢复；月份模式下「可赶 Sprint」提示照常保留。未配置的团队不显示该开关
